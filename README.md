# Portfolio

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

- Edit content in `src/data.js`.
- Project screenshots live in `public/projects/` (referenced by `image:` in `src/data.js`).
- Replace `public/profile.jpg` and `public/Resume.pdf` to update your photo and resume.
- The contact form posts to Formspree (form ID in `src/components/Contact.jsx`) and messages arrive in your email inbox.
- Deploy `dist/` on Vercel or Netlify.
